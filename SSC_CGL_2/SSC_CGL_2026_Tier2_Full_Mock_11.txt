Question:
If the 9-digit number 7x23568y4 is divisible by 88, then what is the value of (x + y)?

Options:
A) 8
B) 6
C) 4
D) 10

Correct Answer:
B) 6

Detailed Solution:
A number is divisible by 88 if it is divisible by both 8 and 11.
1. Divisibility by 8:
The last three digits (8y4) must be divisible by 8.
Numbers ending in 4 divisible by 8 in 800-series:
824 (divisible), 864 (divisible).
So, y can be 2 or 6.

2. Divisibility by 11:
Sum of odd position digits (from right): 4 + 8 + 5 + 2 + 7 = 26.
Sum of even position digits: y + 6 + 3 + x = 9 + x + y.
Difference D = Sum(Odd) - Sum(Even) = 26 - (9 + x + y) = 17 - (x + y).
For divisibility by 11, D must be 0 or a multiple of 11.

Case 1: y = 2
D = 17 - (x + 2) = 15 - x.
For 15 - x to be divisible by 11, x must be 4. (Since 15-4=11).
So, if y=2, then x=4.
Value of (x + y) = 4 + 2 = 6.

Case 2: y = 6
D = 17 - (x + 6) = 11 - x.
For 11 - x to be divisible by 11, x must be 0. (Since 11-0=11).
So, if y=6, then x=0.
Value of (x + y) = 0 + 6 = 6.

In both valid cases, x + y = 6.

Question:
If x + 1/x = 4, then find the value of x^5 + 1/x^5.

Options:
A) 724
B) 728
C) 722
D) 730

Correct Answer:
A) 724

Detailed Solution:
We know the expansion: (x^2 + 1/x^2)(x^3 + 1/x^3) = x^5 + 1/x + x + 1/x^5 = (x^5 + 1/x^5) + (x + 1/x).
Therefore, x^5 + 1/x^5 = (x^2 + 1/x^2)(x^3 + 1/x^3) - (x + 1/x).

Given x + 1/x = 4.
Step 1: Calculate x^2 + 1/x^2
(x + 1/x)^2 = x^2 + 1/x^2 + 2
16 = x^2 + 1/x^2 + 2
x^2 + 1/x^2 = 14.

Step 2: Calculate x^3 + 1/x^3
(x + 1/x)^3 = x^3 + 1/x^3 + 3(x + 1/x)
64 = x^3 + 1/x^3 + 3(4)
64 = x^3 + 1/x^3 + 12
x^3 + 1/x^3 = 52.

Step 3: Calculate Final Value
x^5 + 1/x^5 = (14)(52) - 4
14 * 52 = 728.
728 - 4 = 724.

Question:
In a circle with center O, chords AB and CD intersect at P inside the circle. If Angle AOC = 80 degrees and Angle BOD = 110 degrees, then what is the value of Angle APC?

Options:
A) 95 degrees
B) 85 degrees
C) 100 degrees
D) 105 degrees

Correct Answer:
A) 95 degrees

Detailed Solution:
The angle between two chords intersecting inside a circle is equal to half the sum of the measures of the intercepted arcs (or central angles).
Angle APC intercepts Arc AC.
Angle BPD (vertically opposite to APC) intercepts Arc BD.
Measure of Arc AC = Angle AOC = 80 degrees.
Measure of Arc BD = Angle BOD = 110 degrees.
Angle APC = 1/2 * (Angle AOC + Angle BOD)
Angle APC = 1/2 * (80 + 110)
Angle APC = 1/2 * 190
Angle APC = 95 degrees.

Question:
If 5(sin A)^2 + 14(cos A) = 13, where 0 < A < 90 degrees, what is the value of (tan A + sec A)?

Options:
A) 2
B) 4/3
C) 3
D) 5/4

Correct Answer:
A) 2

Detailed Solution:
Equation: 5 sin^2 A + 14 cos A = 13
Substitute sin^2 A = 1 - cos^2 A:
5(1 - cos^2 A) + 14 cos A = 13
5 - 5 cos^2 A + 14 cos A - 13 = 0
-5 cos^2 A + 14 cos A - 8 = 0
5 cos^2 A - 14 cos A + 8 = 0

Let cos A = x.
5x^2 - 14x + 8 = 0
5x^2 - 10x - 4x + 8 = 0
5x(x - 2) - 4(x - 2) = 0
(5x - 4)(x - 2) = 0
x = 4/5 or x = 2.
Since cosine cannot be greater than 1, x = 4/5.
So, cos A = 4/5.
This represents a 3-4-5 right triangle where Adjacent=4, Hypotenuse=5.
Opposite = 3.
tan A = Opposite/Adjacent = 3/4.
sec A = Hypotenuse/Adjacent = 5/4.
Value of (tan A + sec A) = 3/4 + 5/4 = 8/4 = 2.

Question:
The ratio of incomes of A and B is 5:7. The ratio of their expenditures is 2:3. If A saves Rs. 4,000 and B saves Rs. 5,000, then what is the difference between their incomes?

Options:
A) Rs. 4,000
B) Rs. 3,500
C) Rs. 4,500
D) Rs. 5,000

Correct Answer:
A) Rs. 4,000

Detailed Solution:
Let Incomes be 5x and 7x.
Let Expenditures be 2y and 3y.
Savings = Income - Expenditure.
1) 5x - 2y = 4000
2) 7x - 3y = 5000

To eliminate y, multiply eq(1) by 3 and eq(2) by 2:
3 * (5x - 2y) = 3 * 4000  => 15x - 6y = 12000
2 * (7x - 3y) = 2 * 5000  => 14x - 6y = 10000

Subtract the second derived equation from the first:
(15x - 6y) - (14x - 6y) = 12000 - 10000
x = 2000.

Difference in incomes = 7x - 5x = 2x.
Difference = 2 * 2000 = Rs. 4,000.

Question:
A metallic solid sphere of radius 21 cm is melted and recast into a frustum of a cone. The radius of the top and bottom of the frustum are 7 cm and 14 cm respectively. What is the height of the frustum?

Options:
A) 112 cm
B) 108 cm
C) 96 cm
D) 120 cm

Correct Answer:
B) 108 cm

Detailed Solution:
Volume of Sphere = 4/3 * pi * r^3
V_sphere = 4/3 * pi * (21)^3 = 4/3 * pi * 9261 = 12348 pi.

Volume of Frustum = 1/3 * pi * h * (R^2 + r^2 + Rr)
Given R = 14 cm, r = 7 cm.
R^2 = 196
r^2 = 49
Rr = 14 * 7 = 98
Sum = 196 + 49 + 98 = 343.
V_frustum = 1/3 * pi * h * 343.

Equating Volumes:
12348 pi = (343 / 3) * pi * h
h = (12348 * 3) / 343
12348 / 343 = 36.
h = 36 * 3 = 108 cm.

Question:
Find the Standard Deviation of the following data set: 10, 12, 14, 16, 18, 20, 22.

Options:
A) 4
B) 2
C) 6
D) 8

Correct Answer:
A) 4

Detailed Solution:
The data set forms an Arithmetic Progression.
Data: x_i = {10, 12, 14, 16, 18, 20, 22}
Count (N) = 7.
Mean (x_bar) = 16 (Middle term).

Calculate deviations (d = x_i - mean):
{-6, -4, -2, 0, 2, 4, 6}

Squares of deviations (d^2):
{36, 16, 4, 0, 4, 16, 36}

Sum of squares (Sigma d^2) = 36 + 16 + 4 + 0 + 4 + 16 + 36 = 112.
Variance = (Sigma d^2) / N = 112 / 7 = 16.
Standard Deviation = sqrt(Variance) = sqrt(16) = 4.

Question:
How many factors of the number N = 2^4 * 3^3 * 5^2 * 7^1 are perfectly divisible by 12 but NOT divisible by 60?

Options:
A) 24
B) 18
C) 36
D) 12

Correct Answer:
B) 18

Detailed Solution:
N = 2^4 * 3^3 * 5^2 * 7^1.
Prime factorization of 12 = 2^2 * 3^1.
Prime factorization of 60 = 2^2 * 3^1 * 5^1.

We are looking for factors of the form F = 2^a * 3^b * 5^c * 7^d such that:
1. F is divisible by 12 => a >= 2 and b >= 1.
2. F is NOT divisible by 60 => it is NOT the case that (a >= 2 and b >= 1 and c >= 1).

Since condition (1) enforces a >= 2 and b >= 1, the only way to satisfy condition (2) is if c < 1.
In the given number N, the power of 5 is 2 (so c can be 0, 1, 2).
For c < 1, c must be 0. (1 choice only).

For the other exponents:
a can be chosen from {2, 3, 4} (Given N has 2^4) -> 3 choices.
b can be chosen from {1, 2, 3} (Given N has 3^3) -> 3 choices.
d can be chosen from {0, 1} (Given N has 7^1) -> 2 choices.

Total such factors = (Choices of a) * (Choices of b) * (Choices of c) * (Choices of d)
Count = 3 * 3 * 1 * 2 = 18.
