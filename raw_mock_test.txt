Question 1: Select the related word: Book : Author :: Statue : ?

Correct Answer: A) Sculptor

Detailed Solution:
A book is created by an author, similarly a statue is created by a sculptor.


Question 2: Find the odd one out: 121, 169, 225, 256, 289

Correct Answer: C) 256

Detailed Solution:
All are perfect squares: 11²=121, 13²=169, 15²=225, 16²=256, 17²=289. But 256 is the only even number in the list, making it the odd one out.


Question 3: If CLOUD is coded as ENQWF, how will PLANT be coded?

Correct Answer: A) RNCPV

Detailed Solution:
Each letter is shifted +2 (C→E, L→N, O→Q, U→W, D→F), so PLANT becomes P→R, L→N, A→C, N→P, T→V = RNCPV ⇒ Option A 😡


Question 4: Complete the series: 2, 6, 12, 20, 30, ?

Correct Answer: A) 42

Detailed Solution:
Pattern: 1×2=2, 2×3=6, 3×4=12, 4×5=20, 5×6=30, so 6×7=42.


Question 5: A man walks 8 km towards North, then turns right and walks 6 km...

Correct Answer: A) 10 km

Detailed Solution:
This forms a right triangle. Distance = √(8² + 6²) = √(64 + 36) = √100 = 10 km.


Question 6: Select the related number: 7 : 56 :: 9 : ?

Correct Answer: C) 90

Detailed Solution:
7 × (7 + 1) = 56, so applying the same rule 9 × (9 + 1) = 90


Question 7: If A means +, B means -, C means ×, D means ÷, then what is 18 C 3 A 6 D 2 B 5?

Correct Answer: A) 52

Detailed Solution:
18 × 3 + 6 ÷ 2 - 5 = 54 + 3 - 5 = 52.


Question 8: Find the missing number: 3, 7, 15, 31, 63, ?

Correct Answer: A) 127

Detailed Solution:
Pattern: ×2+1. 3×2+1=7, 7×2+1=15, 15×2+1=31, 31×2+1=63, 63×2+1=127.


Question 9: Select the odd one out: Mars, Jupiter, Saturn, Neptune, Pluto

Correct Answer: D) Pluto

Detailed Solution:
All except Pluto are planets in our solar system. Pluto was reclassified as a dwarf planet in 2006.


Question 10: If TEMPLE is coded as VGORNG, how will CHURCH be coded?

Correct Answer: A) EJWTJG

Detailed Solution:
Each letter shifted forward by 2: T→V, E→G, M→O, P→R, L→N, E→G. So CHURCH: C→E, H→J, U→W, R→T, C→E, H→J = EJWTJG.


Question 11: A is older than B. C is younger than D but older than A. Who is the oldest?

Correct Answer: D) D

Detailed Solution:
From the information: D > C > A > B. So D is the oldest.


Question 12: Complete the series: AZ, BY, CX, DW, ?

Correct Answer: A) EV

Detailed Solution:
Pattern: First letter goes forward (A,B,C,D,E), second letter goes backward (Z,Y,X,W,V). So next is EV.


Question 13: If 15th August 2025 is Friday, what day is 15th November 2025?

Correct Answer: A) Saturday

Detailed Solution:
Days from 15 Aug to 15 Nov: Aug(16) + Sep(30) + Oct(31) + Nov(15) = 92 days. 92 mod 7 = 1. Friday + 1 day = Saturday.


Question 14: Select the related letters: ACE : BDF :: GIK : ?

Correct Answer: A) HJL

Detailed Solution:
Each letter is shifted forward by 1: A→B, C→D, E→F. Similarly, G→H, I→J, K→L = HJL.


Question 15: Find the value: If 2ˣ = 32, then x = ?

Detailed Solution:

Question 17: If the day after tomorrow is Sunday, what day was yesterday?

Correct Answer: A) Thursday

Question 18: Select the odd one out: 23, 29, 31, 37, 39

Question 19: If MADRAS is coded as NBESBT, how will DELHI be coded?

Correct Answer: A) EFMIJ

Detailed Solution:
Each letter shifted forward by 1: M→N, A→B, D→E, R→S, A→B, S→T. So DELHI: D→E, E→F, L→M, H→I, I→J = EFMIJ.


Question 20: Find the next number: 1, 4, 9, 16, 25, ?

Correct Answer: A) 36

Detailed Solution:
Perfect squares: 1²=1, 2²=4, 3²=9, 4²=16, 5²=25, so 6²=36.

Question 22: Complete the series: 5, 8, 13, 21, 34, ?

Correct Answer: A) 55

Detailed Solution:
Fibonacci sequence: each number is sum of previous two. 5+8=13, 8+13=21, 13+21=34, 21+34=55.

Question 51: If x + 1/x = 4, find x² + 1/x².

Correct Answer: A) 14

Detailed Solution:
We know x² + 1/x² = (x + 1/x)² - 2 = 4² - 2 = 16 - 2 = 14.


Question 52: A train 150 m long crosses a pole in 9 seconds. What is the speed of the train?

Correct Answer: B) 60 km/h

Detailed Solution:
Speed = Distance/Time = 150m/9s = 50/3 m/s = (50/3) × (18/5) = 60 km/h.


Question 53: The average of 5 numbers is 28. If one number is excluded, the average becomes 26. What is the excluded number?

Correct Answer: A) 36

Detailed Solution:
Sum of 5 numbers = 5 × 28 = 140. Sum of 4 numbers = 4 × 26 = 104. Excluded number = 140 - 104 = 36.


Question 54: If sin θ = 3/5 and θ is acute, find cos θ.

Correct Answer: A) 4/5

Detailed Solution:
Using sin²θ + cos²θ = 1: (3/5)² + cos²θ = 1 → 9/25 + cos²θ = 1 → cos²θ = 16/25 → cos θ = 4/5 (since θ is acute).


Question 55: A man sells an article for ₹1,200 at a profit of 25%. What was the cost price?

Correct Answer: B) ₹960

Detailed Solution:
SP = CP × (100+profit%)/100 → 1200 = CP × 125/100 → CP = 1200 × 100/125 = ₹960.


Question 56: If 2ˣ = 8, find x.

Question 57: The sum of the first 20 natural numbers is:

Question 58: A rectangle has length 12 cm and breadth 8 cm. What is its diagonal?

Correct Answer: A) √208 cm

Using Pythagoras theorem: diagonal² = 12² + 8² = 144 + 64 = 208. So diagonal = √208 cm.


Question 59: If log₁₀2 = 0.3010, find log₁₀8.

Question 60: A can do a work in 15 days and B can do it in 20 days. How long will they take to complete it working together?

Correct Answer: C) 8.57 days

A's rate = 1/15, B's rate = 1/20. Combined rate = 1/15 + 1/20 = 4/60 + 3/60 = 7/60. Time = 60/7 = 8.57 days.
